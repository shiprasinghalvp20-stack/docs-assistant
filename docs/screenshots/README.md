# Screenshots

Images used by the main README. Take them from the running app (http://localhost:8501):

| File | What to capture |
|---|---|
| `ui-chat.png` | A question with its answer, citation and the "Sources" section expanded |
| `ui-upload.png` | The sidebar after uploading a PDF (status + indexed files list) |

On Windows: press **Win + Shift + S**, select the browser window, then paste into Paint and
save as PNG in this folder. Keep them under ~500 KB, and don't capture private documents.
